# TCO-анализ (Total Cost of Ownership)


| Статья затрат                       | Текущая архитектура (Legacy)                                                              | Целевая архитектура (Data Mesh)                                                                                     | Комментарий                                                                                 |
| ----------------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Инфраструктура (on-prem/cloud)      | 300 у.е./год (поддержка старых серверов, СХД, администрирование)                          | 450 у.е./год (облачные ресурсы: VMs, S3, управляемый Kafka, DataHub, Trino)                                         | Облако дороже, но включает эластичность и отказоустойчивость.                               |
| Лицензии ПО                         | 150 у.е./год (SQL Server 2008 (legacy), Power BI Pro, Windows Server)                     | 80 у.е./год (в основном open-source, только Power BI Premium для части пользователей, облачные сервисы по подписке) | Переход на open-source и облачные managed сервисы снижает лицензионные отчисления.          |
| Сопровождение (команда)             | 600 у.е./год (команда DWH, администраторы, поддержка Power Builder)                       | 800 у.е./год (платформенная команда Data Mesh + доменные Data Engineers, DevOps)                                    | Рост затрат на персонал из-за перехода на новые технологии и увеличения числа специалистов. |
| Время аналитиков (ожидание отчётов) | 200 у.е./год (аналитики тратят часы на ожидание batch-отчётов, задержки принятия решений) | 50 у.е./год (самообслуживание сокращает время получения данных, near-real-time доступ)                              | Снижение стоимости задержек благодаря self-service и быстрым запросам.                      |
| Миграция и обучение                 | 0 (нет)                                                                                   | 150 у.е. (разовые затраты: обучение, разработка PoC, миграция данных)                                               | Инвестиции первого года.                                                                    |
| ИТОГО за 1-й год                    | 1250 у.е.                                                                                 | 1530 у.е.                                                                                                           | Целевая архитектура дороже на этапе перехода.                                               |
| ИТОГО за 2-й год                    | 1250 у.е.                                                                                 | 1330 у.е. (без миграционных затрат)                                                                                 | Стоимость снижается, но всё ещё выше из-за облака и команды.                                |
| ИТОГО за 3-й год                    | 1250 у.е.                                                                                 | 1330 у.е.                                                                                                           |
| ИТОГО за 3 года                     | 3750 у.е.                                                                                 | 4190 у.е.                                                                                                           | Разница ≈ 440 у.е. (около 12% выше у целевой архитектуры).                                  |

Таким образом целевая архитектура требует больших первоначальных вложений и ежегодных затрат на облако и персонал, но обеспечивает существенное повышение производительности аналитиков (снижение времени ожидания), гибкость и масштабируемость. С учётом быстрого роста бизнеса и планов по выходу на новые рынки, дополнительные затраты окупаются за счёт ускорения time-to-market и возможности обрабатывать растущие объёмы данных. Кроме того, текущая архитектура (SQL Server 2008) скоро станет неподдерживаемой и небезопасной, что создаёт скрытые риски.
