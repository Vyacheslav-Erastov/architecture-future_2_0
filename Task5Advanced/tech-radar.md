# Расширенный технический радар (Tech Radar)

## Техники (Techniques)

| Техника / Паттерн         | Статус | Пояснение                                                                                           |
| ------------------------- | ------ | --------------------------------------------------------------------------------------------------- |
| Data Mesh                 | Adopt  | Основополагающий паттерн децентрализации данных с доменной ответственностью.                        |
| Event-Driven Architecture | Adopt  | Асинхронное взаимодействие доменов через события — основа целевой архитектуры.                      |
| Self-service BI           | Adopt  | Бизнес-пользователи самостоятельно строят отчёты через портал, снижая зависимость от ИТ.            |
| Data Product              | Adopt  | Данные рассматриваются как продукт с чёткими SLA, владельцем и документированием.                   |
| Federated Governance      | Trial  | Федеративное управление данными: общие стандарты при автономии доменов. Внедряется на втором этапе. |
| Data Contract             | Trial  | Контракты между провайдерами и потребителями данных (схемы, качество).                              |
| Data Observability        | Assess | Мониторинг качества данных и lineage (планируется после пилота).                                    |

## Платформы (Platforms)

| Платформа                                    | Статус | Пояснение                                                                                             |
| -------------------------------------------- | ------ | ----------------------------------------------------------------------------------------------------- |
| Облачная инфраструктура (Yandex Cloud / AWS) | Adopt  | Целевая платформа для размещения всех компонентов, отказоустойчивость, масштабирование.               |
| Apache Kafka (Confluent)                     | Adopt  | Событийная шина для всех доменных событий, с Schema Registry и KSQL.                                  |
| Data Lakehouse (S3 + Iceberg + Nessie)       | Adopt  | Хранилище аналитических данных с поддержкой ACID и версионирования.                                   |
| Trino (Presto)                               | Adopt  | Распределённый SQL-движок для запросов к Data Lakehouse и другим источникам.                          |
| DataHub                                      | Adopt  | Каталог данных для обнаружения и управления метаданными дата-продуктов.                               |
| Apache Airflow                               | Adopt  | Оркестрация ETL/ELT-процессов и подготовки витрин.                                                    |
| Kubernetes                                   | Adopt  | Оркестрация контейнеров для микросервисов и платформенных сервисов.                                   |
| Power BI / Superset                          | Trial  | BI-инструменты: Power BI остаётся для совместимости, Superset изучается как open-source альтернатива. |

## Инструменты (Tools)

| Инструмент           | Статус | Пояснение                                                                             |
| -------------------- | ------ | ------------------------------------------------------------------------------------- |
| Kafka Connect        | Adopt  | Интеграция источников и приёмников данных (БД, S3, легаси).                           |
| Debezium             | Adopt  | CDC для захвата изменений из операционных БД и публикации в Kafka.                    |
| dbt                  | Trial  | Трансформация данных в Data Lakehouse (SQL-модели).                                   |
| Terraform            | Adopt  | Управление инфраструктурой как кодом (IaC).                                           |
| Keycloak             | Adopt  | Централизованный IAM для аутентификации и авторизации.                                |
| Prometheus + Grafana | Adopt  | Мониторинг инфраструктуры и приложений.                                               |
| Apache Flink         | Assess | Потоковая обработка для near-real-time аналитики (будет оцениваться на втором этапе). |

## Языки и фреймворки (Languages & Frameworks)

| Язык/Фреймворк     | Статус | Пояснение                                                                    |
| ------------------ | ------ | ---------------------------------------------------------------------------- |
| Java (Spring Boot) | Adopt  | Основной язык для новых микросервисов (финтех, ядро платформы).              |
| Go                 | Trial  | Используется для высоконагруженных сервисов (API Gateway, некоторые домены). |
| Python             | Adopt  | Для ИИ-сервисов, аналитических скриптов, Airflow DAG.                        |
| React              | Adopt  | Фронтенд портала самообслуживания.                                           |
| SQL                | Adopt  | Основной язык для аналитических запросов и трансформаций.                    |
