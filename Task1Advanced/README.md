# Задание 1. Модульная инфраструктура для нескольких сред

Модуль `vm` создаёт виртуальную машину с заданными характеристиками, загрузочным диском из указанного образа, дополнительным диском и публичным IP-адресом.

## Параметры модуля

| Имя          | Описание                          | Тип    |
| ------------ | --------------------------------- | ------ |
| vm_name      | Имя ВМ                            | string |
| cores        | Количество ядер CPU               | number |
| memory       | Объём RAM (ГБ)                    | number |
| disk_size_gb | Размер дополнительного диска (ГБ) | number |
| subnet_id    | ID подсети                        | string |
| ssh_key      | Публичный SSH-ключ                | string |

## Выходные данные

| Имя                | Описание                         |
| ------------------ | -------------------------------- |
| vm_id              | ID созданной ВМ                  |
| vm_name            | Имя ВМ                           |
| internal_ip        | Внутренний IP-адрес              |
| external_ip        | Внешний IP-адрес (если назначен) |
| additional_disk_id | ID дополнительного диска         |

## Запуск для разных окружений

Для каждого окружения подготовлена отдельная директория с собственным `tfvars`-файлом.

1. Предварительно необходимо экспортировать переменный для Yandex Cloud:

```
export YC_TOKEN=$(yc iam create-token)
export YC_CLOUD_ID=$(yc config get cloud-id)
export YC_FOLDER_ID=$(yc config get folder-id)
```

2. Необходимо скопировать файл с примером `.tfvar`-файла

Пример для dev-окружения
```
cd envs/dev
cp dev.tfvars.example dev.tfvars
```

И добавить туда свой ssh-ключ и ID-подсети

```
ssh_key      = ""
subnet_id    = ""
```

3. Проинициализировать Terraform
   
```
terraform init
```

4. Просмотреть план изменений
   
```
terraform plan -var-file=dev.tfvars
```

5. Применить конфигурацию

```
terraform apply -var-file=dev.tfvars
```

Для окружений `stage` и `prod` действия аналогичны, используйте соответствующие `tfvars`-файлы
